Sourav Ghosh — Product Space-style Portfolio

Open index.html to preview locally.

Deployment:
- Upload the contents of this folder to Netlify, Vercel, GitHub Pages, or another static host.
- index.html is the portfolio directory.
- profile.html is Sourav's profile.
- assets/resume/Sourav_Ghosh_PM.pdf is the PM resume used by the View Resume buttons.
- assets/presentations/ contains the four presentation PDFs and cover images added to the Projects section.

No build step is required; this is a static HTML/CSS site.
